# Contribuindo

Contribuições são bem-vindas por pull request. Para mudanças que alterem o comportamento de envio, inclua antes/depois reproduzíveis e atualize os testes e limitações relevantes.

## Antes de enviar

- Execute `npm test` com Node.js 18 ou superior.
- Confirme que não foram adicionadas permissões, chamadas de rede ou coleta de dados desnecessárias.
- Para mudanças em seletores ou integração com o WhatsApp Web, descreva o navegador, idioma e passos de teste real. Não inclua conteúdo de conversas ou dados pessoais.
- Atualize a documentação quando o comportamento, armazenamento, permissões ou limitações mudarem.

A suíte simulada não substitui verificação manual no navegador. Não declare compatibilidade com uma versão do WhatsApp Web sem teste real documentado.
