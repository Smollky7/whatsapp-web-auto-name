# WhatsApp Web Name Prefix

Extensão para Google Chrome que adiciona automaticamente um prefixo com seu nome antes de cada mensagem enviada no WhatsApp Web.

Ideal para atendimentos, equipes, freelancers ou qualquer pessoa que precise se identificar em conversas no WhatsApp Web.

---

## 🚀 Funcionalidades

- ✅ Adiciona automaticamente o nome antes da mensagem
- ✅ Chave liga/desliga
- ✅ Campo para definir o nome
- ✅ Preview de como a mensagem será enviada
- ✅ Configurações salvas localmente (não se perdem ao fechar o navegador)
- ✅ Funciona diretamente no WhatsApp Web
- ✅ Não coleta dados do usuário
